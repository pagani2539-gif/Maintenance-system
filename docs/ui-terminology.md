# มาตรฐานคำศัพท์ส่วนติดต่อผู้ใช้

ระบบใช้ “อุปกรณ์” เป็นคำหลักสำหรับสิ่งของที่อยู่ในคลัง ถูกเบิก ยืม คืน ซ่อม เคลม จัดซื้อ หรือติดตั้งที่สถานี

| ใช้คำนี้ | แทนคำเดิม | หลักการใช้ |
| --- | --- | --- |
| อุปกรณ์ | พัสดุ, สินค้า, อะไหล่ | คำหลักเดียวในข้อความที่ผู้ใช้เห็น |
| คลังอุปกรณ์ | คลังพัสดุ, คลังสินค้า, คลังอะไหล่ | ใช้กับพื้นที่/ระบบจัดเก็บ |
| รายการอุปกรณ์ | รายการพัสดุ, รายการสินค้า | ใช้กับรายการในตารางหรือเอกสาร |
| ยอดคงเหลือ | สต็อกคงเหลือ, ตัดสต็อก | ใช้กับจำนวนที่มีอยู่ในคลัง |
| เกณฑ์แจ้งเตือนขั้นต่ำ | จุดเตือนสต็อกขั้นต่ำ | ใช้กับค่า `min_stock` ที่แสดงต่อผู้ใช้ |
| รายการเคลื่อนไหว | ธุรกรรม, รายการธุรกรรม | ใช้กับประวัติรับเข้า เบิก ยืม คืน และปรับยอด |
| อุปกรณ์ติดตั้ง | สินทรัพย์, สินทรัพย์ติดตั้ง | ใช้กับอุปกรณ์ที่ติดตั้งและติดตามรายชิ้น |
| อุปกรณ์ประจำตัวช่าง | อะไหล่ในมือช่าง | ใช้กับอุปกรณ์ที่อยู่ในชุดประจำตัวช่าง |
| หมายเลขเครื่อง (S/N) | หมายเลขเครื่อง | ใช้ครั้งแรกหรือในบริบทอธิบาย; ตารางแคบใช้ `S/N` ได้ |
| รุ่น (Model) | รุ่น/แบรนด์, รุ่น/model | ใช้ใน label, header และเอกสาร |

ชื่อ field, enum, status ที่บันทึกในฐานข้อมูล และค่า API ยังคงเดิมเพื่อ compatibility เช่น `inventory_id`, `product_name`, `ADD_STOCK`, `WITHDRAW`, `RETURN`, `BORROW` และ `ADJUSTMENT`
